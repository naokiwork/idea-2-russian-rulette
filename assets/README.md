# Assets Guide

Drop marketing-ready screenshots, mockups, and gameplay recordings here. Suggested naming:

- `hero-main.png` — 1600×900 hero capture
- `flow-lobby.png` — lobby wireframe
- `flow-results.png` — ranking view
- `demo.mp4` / `demo.gif` — 10–20s gameplay loop

> Keep binary files lightweight (<3 MB) to avoid inflating git history.
