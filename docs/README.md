# Documentation Hub

This directory aggregates the research artifacts that shape the Russian Roulette Shot Game app. Each document can be referenced directly from product specs, design reviews, and onboarding materials.

## Contents

1. **UI/UX Competitive Analysis** — [`psycatgames_uiux_analysis.md`](./psycatgames_uiux_analysis.md)
   - Full breakdown of the PsyCat Games experience (visual system, navigation, UX heuristics, improvement backlog).
2. **Experience Slides / Flow Specs** — [`russian_roulette_game_slides.md`](./russian_roulette_game_slides.md)
   - Slide-style spec capturing the game scenarios, wireframes, and MVP scope.

## Usage Guidelines

- Keep historical analyses immutable; add errata at the bottom with a date stamp instead of rewriting sections.
- If you add new research, create a dedicated subfolder (e.g., `docs/research/2025-12/`) and cross-link it from this index.
- Link back to specific headings in feature PRs so reviewers see the source inspiration quickly.
